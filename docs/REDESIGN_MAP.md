# Freyra — redesignkort

## Fast udgangspunkt og afgrænsning

Kortlagt **før UI-ændringer** fra `codex/haderslev-demo-2710`, commit `625781906a4f49d120b6b3581261279dd889e6de`. Arbejdsgren: `codex/redesign-2710`. Base og main røres ikke. Kun præsentation, navigation, lokal formularstate, hjælpetekst og dokumentation ændres. Motor, beregninger, API, database, Supabase, RLS, datastrukturer, eksisterende inputværdier og faglige godkendelseskrav bevares.

Alle eksisterende routes bevares. Demoens eksisterende afgrænsning bevares: allerede skjulte prototypeværktøjer og automatisk AI frigives ikke. Kilder er en ny læsende katalogside. Øvrige værktøjer, der er tilgængelige uden demoflaget, flyttes fra hovedmenuen til Sager → Flere fagværktøjer. Historiske rapporter og deres grundlag ændres ikke.

## Funktioner og ny placering

| Nuværende funktion | Nyt sted | Bevares / vises først |
|---|---|---|

| Fotopunkter, datakilder, indikatorer, handlinger, roller, dokumenter, medier, miljødata, livekort | Flere sagsværktøjer → de eksisterende projektfaner | Alle faner og redigeringshandlinger bevares uden demoflaget; demoens eksisterende allowlist bevares |
| Samlet overblik, byggeri, beslutninger, finansiering, offentlig effekt, ledger, rapportbibliotek, administration, systemtest | Sager → Flere fagværktøjer | Samme routes og underfaner; ingen ekstra hovedmenupunkter |
| Kildekatalog og metodebeskrivelser | Kilder | Læsende katalog. Katalogstatus er ikke den konkrete sags kildedækning |
| Organisering, arbejdspladsvalg, kontomenu, logout | Sidebar/brugermenu | Samme identitet og adgang; indstillinger flyttes til brugermenu |
| Baggrundsarbejde og opgaver | Aktivitetsbakke, kun visning | Faktiske igangværende queries/mutationer og gemte mangler; ingen opdigtet jobkø, antal eller færdigstatus |

## Status og nulstilling

Færdig betyder dokumenteret teknisk delresultat med tydelig afgrænsning, ikke faglig/kommunal accept. Datamangler og læsefejl skal fortsat fremgå. Verificering og beplantningsaccept må ikke markeres færdig på grund af navigation. Næste-knappen flytter kun visningen og gemmer eller godkender intet.

Nulstil til standard ændrer kun den lokale formulars opsætning til de oprindelige standardværdier eller det oprindelige gemte udgangspunkt. Ingen API-kald, sletning af dokumentation eller ny gemning udføres. Valg af originaler, sag, undersøgelse, rapportversion og faglige beslutninger er identitets-/dokumentationsvalg og nulstilles ikke som beregningsparametre. Hvor der ikke findes en global standard, må UI'et ikke opfinde en.
